# Clinify Repository Structure

> Repository organization and project layout.

---

# Purpose

This document describes the organization of the Clinify source repository and the purpose of each major directory.

---

# Repository Layout

```
clinify/
├── clinify/          # Application source
├── docs/             # Project documentation
├── public/           # CSS, JS, Images
├── fixtures/         # ERPNext fixtures
├── report/           # Custom reports
├── scripts/          # Development utilities
├── www/              # Website pages
└── config/           # Frappe configuration
```

---

# Repository Principles

- Production code only.
- Git is the source of history.
- Documentation lives inside the repository.
- Avoid duplicate files.
- Archive before deleting.

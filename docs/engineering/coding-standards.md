# Coding Standards

> Engineering rules used throughout Clinify.

---

# General Principles

- Architecture before implementation.
- Backend → Frontend → UX.
- Extend ERPNext instead of modifying core.
- Keep business logic in Python.
- Keep JavaScript focused on UI.
- Keep code readable and maintainable.

---

# Git Rules

- Test before commit.
- Commit before deployment.
- One logical change per commit.

---

# Repository Rules

- Archive before deleting.
- Avoid duplicate implementations.
- Keep documentation updated.

---
